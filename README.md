# dea-catalog-ontologies

> DEA L1 catalog repository — domain OWL/RDF ontologies (fintech, healthcare).

## What this is

Domain ontologies that formalise industry-specific vocabularies as OWL/RDF,
sitting alongside the organisation-wide metamodel
([`dea-metamodel`](https://github.com/technehub-labs/dea-metamodel)) — which
remains the canonical source for DEA entity and relationship definitions.
Domain ontologies specialise; they do not redefine metamodel concepts.

## Status

Scaffold — structure and initial domain ontologies land under
[Project #4 — Catalog Ecosystem](https://github.com/orgs/technehub-labs/projects/4).
